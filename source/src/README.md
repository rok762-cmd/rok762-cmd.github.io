# 실측 스튜디오 · 원본 구조

원본은 기능별 파일로 나뉘어 있고, `build/build.py`가 **파일 이름 순서대로** 합쳐 한 파일로 만듭니다.

- `silcheuk-studio.html`: claude.ai 페이지
- `pwa/index.html`: 앱
- `실측스튜디오_오프라인.html`: 오프라인 파일

모든 파일은 같은 전역 영역을 공유하는 일반 스크립트입니다. 그래서 **뒤 번호 파일이 앞 번호 파일의 함수·변수를 씁니다.** 순서를 바꾸지 마세요.

```
src/
  page.html     껍데기 (head · 화면 틀) — /*@CSS*/, /*@JS*/ 자리에 아래가 들어감
  app.css       화면 스타일
  js/
    00-basics       공통 도구 ($, clamp, uid, store …)
    00-rules        ★ 현장 규칙 표 (장 폭 단위·최대 폭·쿡탑장·도어 폭·뒷턱·키큰장·EP) — 제품·단가 관리 '현장 규칙'에서 수정
    01-domain       품목·장 종류·도어·상판·가전 기본값, 키큰장 자리
    02-state        현장(job)·제품 목록(catalog) 저장/불러오기, 현장 구조 마이그레이션
    03-geometry     면별 칸 배치 계산 (휠라·EP·코너·키큰장·뒷선반)
    04-sizing       칸 폭 정규격 맞춤 (50 단위·쿡탑장·400/350 도어·상하 선·작은 장 자동)
    05-quote        견적 (m 단가·키큰장 3m·직접 수정·할인), 부재 목록
    06-svg-tech     도면 그리기 기본 + 제작 도면 정면
    07-scene        고객용 그림, B면 좌우 보정, 치수 표시
    08-paper        종이 도면·견적서 페이지
    09-house        집 전체 평면·도배, 집 3D, 평면도 사진
    10-viewer-items 크게 보기, 한 현장 여러 품목
    11-export-send  파일 저장, 이메일·카톡 발송, 드라이브 자동 업로드
    12-proposal-plans 한 장 제안서, 손 메모 인식, 방 평면, 동선 삼각형, 전기 도면
    13-server-photo 예시 사진, 서버 저장, 인터넷 연결, 사진 보정·합성
    14-kitchen3d    주방 3D
    15-ui           단계별 화면 (실측·플랜·도어·결과물)
    16-validator    제작 검증기
    17-manager      제품·단가 관리 (현장 규칙 탭 포함)
    18-actions      버튼 동작 모음 (ACT)
    19-drawing-set  측면·배면·평면·상판 도면, 제작지시서
    20-as-data      AS·고객 데이터
    21-bath         욕실 설계·견적·3D
    22-as-ui        AS·고객 화면·문서·동작
    23-events       화면 입력 연결 (클릭·변경)
    24-field-present 현장/사무실 화면, 고객 발표
    25-data-backup  전체 백업·복원, 사무실→태블릿
    26-factory      공장 출력 (도어 발주서·재단·하드웨어)
    27-measure3pt   3점 실측, 블루투스 레이저
    99-boot         시작
```

## 고치는 법

1. `src/` 안의 해당 파일을 고칩니다.
2. `python3 build/build.py`로 세 가지 결과물을 만듭니다.
3. `python3 tests/run_all.py`로 전체 점검을 돌립니다. 빌드, 모듈 합치기, 기능별 점검, 오프라인·앱 회귀가 모두 통과해야 배포합니다.
